
# Agentic RAG

An AI-powered document question-answering system, built with Java, Spring Boot, and a locally running LLM using Ollama.

## Planned Features

- Document ingestion and text extraction
- Text chunking and embedding generation
- Semantic retrieval using a vector database
- Local LLM-based answer generation
- Web-based chat interface
- Future extension to Agentic RAG with planning, validation, and memory
